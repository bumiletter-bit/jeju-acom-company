# 제주아꼼이네 오피스 — UI/UX 디자인 개선 제안서

> **제안일**: 2026-07-26
> **제안자 롤**: 디자인·홈페이지 10년차 마케팅 대표 관점
> **대원칙**: 🔒 **기능은 절대 건드리지 않는다.** 데이터·저장·등록·계산 로직 무수정, 오직 '보이는 방식'만 바꾼다.
> **디자인 기준**: 현재 확정된 테마 — 인디고(#4F46E5)/화이트, Pretendard, 둥근 12~14px, 은은한 그림자, 커스텀 달력(akm-cal)·공통 표 디자인과 한 식구로.

## 1. ★ 메인 제안 — 일정 메뉴 (주간/월간/연간 뷰)

지금 일정 화면은 "월간 달력 하나"입니다. 실무에서는 **"오늘/이번 주 뭐 하지?"**(직원)와 **"올해 행사 언제였지?"**(대표)가 다른 질문인데, 하나의 뷰로 둘 다 감당하고 있습니다.

### 1-1. 뷰 전환 토글 (주간 | 월간 | 연간)
- 달력 제목 옆에 순위관리의 1·2·3·6개월 버튼과 똑같은 **pill 토글**: `주간 | 월간 | 연간` (기본 = 월간, 지금과 동일).
- 보기만 추가하는 것 — 일정 데이터·등록·체크 기능은 지금 것 그대로 사용.

**주간 뷰** (직원의 아침 화면)
- 이번 주 7일을 **세로 카드 리스트**로: 요일마다 한 줄 카드, 오늘은 인디고 테두리+옅은 인디고 배경으로 확 띄움.
- 월간에선 좁은 셀에 눌려 있던 일정이 주간에선 **줄임 없이 전부 보임** (체크박스도 그대로).
- 모바일에서 특히 강력 — 스크롤 한 번이면 이번 주 끝.

**연간 뷰** (대표의 큰 그림)
- **12개월 미니 달력 그리드**(4×3). 일정 있는 날은 유형 색 **점(dot)**으로만 표시.
- 행사·상품 등록 몰린 달이 한눈에 보임 → 월 클릭하면 그 달 월간 뷰로 점프.
- 성수기(청귤 등) 연간 리듬을 보는 용도.

### 1-2. 월간 달력 스킨 다듬기 (뷰 추가와 별개로 바로 가능)
- **오늘 셀**: 날짜 숫자를 인디고 원형 배지로 (지금은 오늘이 잘 안 튐).
- **일정 칩**: 유형별 파스텔 배경 + 왼쪽 3px 컬러바(행사=핑크, 상품=앰버, 당직=인디고, 일반=그레이) — 지금보다 대비를 살짝 올려 글자 가독성 ↑.
- 지난달/다음달 날짜는 더 흐리게, 주말 색(일 빨강/토 파랑)은 지금 유지.
- 일정 4건 초과 시 "+N건 더보기" 배지 → 클릭하면 그 날 일정 전체 팝오버(등록 기능 아님, 보기만).
- 셀 hover 시 아주 옅은 인디고 배경 (클릭 가능한 곳이라는 신호).

### 1-3. 상단 "오늘 브리핑" 스트립
- 환영 인사 아래 얇은 한 줄: **`오늘 일정 3건 · 이번 주 행사 1건 · 다가오는 D-day: 청귤 오픈 D-5`**
- 이미 불러온 데이터를 요약해서 보여주기만 함. 달력 안 훑어도 오늘 상황 파악 끝.
- "오늘" 버튼 추가: 다른 달 보다가 한 번에 이번 달·오늘로 복귀.

## 2. 공통 디자인 (전 메뉴에 같이 깔리는 것)

| 항목 | 제안 | 효과 |
|---|---|---|
| 페이지 헤더 | 모든 페이지 제목을 같은 규격(제목 + 옅은 한 줄 설명 + 우측 액션 버튼)으로 | 화면마다 들쭉날쭉한 첫인상 통일 |
| 상태 배지 | 승인/대기/반려, 사용중/꺼짐, 판매중/준비중을 **한 가지 배지 시스템**(초록/앰버/빨강/그레이 파스텔+점)으로 | 지금 화면마다 배지 모양이 조금씩 다름 |
| 빈 화면 | "기록이 없습니다" 텍스트 → 아이콘+안내문+행동 유도("첫 일정을 등록해 보세요") | 비어 있어도 방치된 느낌 X |
| 버튼 위계 | Primary(인디고 채움)/Outline/텍스트 3단계 규칙을 전 화면 통일 | 눌러야 할 버튼이 명확해짐 |
| 숫자 표기 | 금액·수량은 전부 우측 정렬 + tabular-nums(자릿수 정렬 폰트) + 마이너스 빨강 | 정산·지출 화면 스캔 속도 ↑ |
| 로딩 | "불러오는 중..." 텍스트 → 회색 스켈레톤(뼈대) 애니메이션 | 체감 속도 ↑, 요즘 서비스 느낌 |

## 3. 메뉴별 디자인 제안 (전부 기능 무수정 — 보이는 것만)

- **순위관리** ✅ 이번에 완료. +α: 추이 차트 색을 테마 팔레트(인디고 계열)로 맞추면 화면 전체가 한 톤이 됩니다.
- **업무일지**: 목록을 **타임라인 카드**로 — 날짜 세로선 + 작성자 색 점 + 카드. 하루 흐름이 읽히는 피드 느낌.
- **마이 플래너**: 할 일/메모/D-day를 **위젯 카드 그리드**로 정리, D-day는 큰 숫자 강조.
- **기안서류**: 문서 상태를 배지 시스템으로, 상세엔 **결재 단계 스텝퍼**(작성→대기→승인)를 시각화. 서류가 '진행 중인 일'로 보이게.
- **지출결의서**: 금액을 카드 우측에 크게, 영수증 첨부는 썸네일 그리드로.
- **정산관리**: 상단에 **요약 스탯 카드 3~4장**(이번 달 정산액·미정산 건수 등 — 이미 계산되는 값 재배치). 표는 이번 공통 디자인 적용됨.
- **품목별 금액**: 거래처 색(파랑/노랑/보라)을 **범례 칩**으로 상단에 명시 + 행 색은 유지하되 채도 살짝 낮춰 눈 피로 ↓.
- **박스재고**: 박스별 잔여 수량에 **미니 게이지 바**(안전/주의/부족 색) — 숫자보다 직관적.
- **송장변환**: 화면 상단에 **단계 표시**(① 불러오기 → ② 확인 → ③ 변환·다운로드). 버튼 많은 화면이라 순서가 보이면 실수 ↓.
- **CS처리방·문의 관리**: 템플릿/시나리오 목록에 검색창 + 카테고리 칩, 미리보기는 **말풍선(채팅) 스타일** — 고객이 보는 모습 그대로 확인.
- **데이터관리**: 연결/타이머 카드를 같은 규격(아이콘+이름+초록불 상태+마지막 실행)으로 통일, ON/OFF는 **토글 스위치** 모양으로.
- **내 정보**: 프로필 카드(색 아바타 크게 + 잔여연차/당직 요약)로.
- **AGENT OFFICE**: 픽셀 사무실 컨셉은 유니크한 자산이라 **그대로 유지** 추천. 주변 카드 톤만 본 테마와 맞춤.

## 4. 진행 순서 제안 (콜 주시면 이 순서로)

| 차수 | 내용 | 성격 |
|---|---|---|
| **1차** | 일정 메뉴: 월간 스킨 + 오늘 브리핑 + 주간/연간 뷰 | 이번 제안의 본체 |
| **2차** | 공통: 배지 시스템·빈 화면·버튼 위계·숫자 표기 통일 | 전 화면 체감 |
| **3차** | 메뉴별 개선(정산 스탯 카드 → 송장변환 단계 표시 → 나머지) | 하나씩 확인받으며 |

- 각 차수 배포 후 대표님 확인 → 다음 차수. 마음에 안 들면 그 항목만 원복 가능하게 CSS 위주로 작업.
- 🔒 재확인: 등록·저장·변환·정산 등 **기능 코드는 손대지 않습니다.** 주간/연간 뷰도 이미 불러온 일정 데이터를 다르게 '그리는' 것뿐입니다.
