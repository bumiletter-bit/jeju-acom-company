## 3. 서체

- **Pretendard 단일** (index.html에서 CDN 로드, 폴백: 시스템 한글 폰트). 화면 어디에도 다른 서체 지정 금지.
- 예외 2곳만: ①AGENT OFFICE 로그·프롬프트 콘솔 = Consolas(고정폭) ②거래처 발송 캡처 이미지·기안 인쇄물 = 맑은 고딕(받는 쪽 문서 모양 유지).
- 숫자(금액·수량)는 `font-variant-numeric: tabular-nums` + 우측 정렬 + 마이너스 빨강.

## 4. 모양 규칙 (입체감의 정체)

- 둥근 모서리: 카드 14px, 표·박스 12px, 버튼 10px, 칩/배지 999px(알약).
- 그림자(은은하게): 기본 `0 1px 3px rgba(16,24,40,.06)` · 떠있는 요소 `0 4px 16px -6px rgba(16,24,40,.12)` · 주 버튼 `0 6px 16px -6px rgba(79,70,229,.55)`.
- 헤더류 배경: 옅은 그라데이션 `linear-gradient(#FBFBFD, #F4F5F8)`.
- 호버: 표 행 `#F8F9FC`, 인디고 요소는 `--primary-light`.

## 6. 레이아웃·모바일 원칙

- 표가 조건(필터)·집계와 함께 있으면: 조건·집계는 화면에 남고 표만 래퍼 안에서 스크롤(엑셀 틀고정 느낌).
- 모바일(≤768px): 일정 헤더는 2줄(제목+새로고침 / 토글·오늘·이동), 긴 텍스트는 칸 밖으로 밀지 말고 줄바꿈·축소(`min-width:0` 필수), 터치 버튼 40px+.
- 모달: 완료 체크 등 반복 조작은 **창을 닫지 않고** 상태만 갱신(대표 지시, 정산 날짜 모달 참조).

## 7. 작업 절차 (디자인 건드릴 때)

1. 이 가이드 + `theme.css`(색·모양 오버레이) + `styles.css` 하단 블록들(v5.9.69~79 주석) 확인.
2. 새 스타일은 기존 토큰·컴포넌트 재사용. 화면별 예외는 클래스 스코프로(전역 오염 금지).
3. 큰 변경은 시안(HTML 목업, `디자인시안_v1_2026-07-26.html` 방식)으로 먼저 보여주고 대표 "콜" 후 반영.
4. 배포 전: `node --check` → 버전·캐시(v=NNN) 상향 → CHANGELOG → `npm run deploy`. 실험성 변경은 원복 쉽게 **한 블록**으로.
5. 병행 세션 주의: 커밋 전 `git log`·`git status` 확인, 내 파일만 add.
