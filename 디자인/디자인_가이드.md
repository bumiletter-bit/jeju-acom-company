### 2-1. 의미색 단계 — 바탕 · 테두리 · 글자(#1218 · 2026-11-21)

**의미색은 세 단계로 쓴다.** `--danger`·`--success`·앰버 원색은 점·아이콘·채운 단추에만 쓰고, 흰 바탕 위 **글자에는 쓰지 않는다**(흰 바탕 대비 2.5~3.6:1 미달). 글자는 `-ink` 로. 값은 화면에 이미 가장 많이 쓰이던 값 그대로(새 색 아님).

| 뜻 | 바탕 | 테두리 | 글자(흰 바탕 대비) |
|---|---|---|---|
| 위험(빨강) | `--danger-bg #FEF3F2` | `--danger-line #FDA29B` | `--danger-ink #B42318` (6.6:1) |
| 성공(초록) | `--success-bg #ECFDF3` | `--success-line #ABEFC6` | `--success-ink #067647` (7.3:1) |
| 주의(호박) | `--warn-bg #FFFAEB` | `--warn-line #FEDF89` | `--warn-ink #B54708` (5.4:1) |
| 인디고 | `--primary-light #EEF0FF` | `--primary-line #C7CBFF` | `--primary-ink #3730A3` (10:1) |

- **역할대로만 쓴다**: `-bg` = 바탕 · `-line` = 테두리 · `-ink` = 글자. 같은 값이라도 역할이 다르면 직접 색 그대로 둔다(야간 계산이 역할별로 달라서).
- 야간: 이 이름들은 야간에 따로 정의하지 않는다 — `gen-dark.js` 가 값으로 펼쳐 계산한다(styles.css·theme.css·order-organizer.css). 다른 CSS(메모함·최종발주 등)는 자기 야간 블록에서 값을 직접 준다.
- 기본 이름(`--text-mid`·`--border`·`--card-bg`·`--primary`·`--primary-light`·`--bg`)은 야간에 `hand-dark.css` 가 다시 정의하므로 그대로 쓰면 야간도 따라간다.

### 2-2. 강조 방식(#1218 · 대표 「강조 부분만 · 부드럽게 · 과하지 않게」)

- 강조 = **굵은 글 · 큰 숫자 · 옅은 바탕(틴트) · 가는 테두리(손볼 줄은 왼쪽 3px)**. 진하게 채운 판·띠·카드 머리 전체 칠하기 X · 그라데이션 판 X.
- **진한 채움은 화면당 한 곳**(그 화면의 주인공 단추 또는 맨 아래 합계 줄 하나).
- 빨강은 **진짜 문제에만**(정산 대조 차이 큼·박스 넘침 등) — 글자·막대·옅은 바탕까지. 「확인 필요」(모자람·확인 중)는 호박.
- 색만으로 구분하지 않는다 — 「확인 필요」 글·「−」 부호·알약 글자를 같이.
- 정상·완료 줄은 조용히(진한 글자 + 옅은 테두리 알약), 지난날은 흐리게(글자 대비 4.5 이상 유지).

**의미색(변경 금지 — 직원들이 색으로 기억함)**: 행사=보라 `#9333ea` · 상품=초록 `#10b981` · 당직=인디고 · 휴가=티일 `#0CA678` · 일요일 빨강/토요일 파랑 · 거래처(대성=파랑톤·효돈=노랑톤·애월=보라톤 행 배경).

## 3. 서체

- **Pretendard 단일** (index.html에서 CDN 로드, 폴백: 시스템 한글 폰트). 화면 어디에도 다른 서체 지정 금지.
- 예외 2곳만: ①AGENT OFFICE 로그·프롬프트 콘솔 = Consolas(고정폭) ②거래처 발송 캡처 이미지·기안 인쇄물 = 맑은 고딕(받는 쪽 문서 모양 유지).
- 숫자(금액·수량)는 `font-variant-numeric: tabular-nums` + 우측 정렬 + 마이너스 빨강(`--danger-ink` · 「−」 부호 함께).
- **글자 크기 8단(#1218 · #1220 정정 = 대표 11/21)**: 12 · 13 · 14 · 15 · 16 · 18 · 22 · 28px 중에서 고른다(가장 중요한 숫자 하나만 28~32). 본문 14 · 보조·칸 이름 12~13 · 알약 12 · 단추 15(폰 입력 칸 16 = 확대 막기) · 판 제목 16 · 창 제목 18. **12px 미만 금지**(폰). 반 단계(12.5·13.5 등)는 새로 쓰지 않고, 고치는 화면에서 가까운 단으로 묶는다(#1220 발주 메모함 판 = 묶음 끝).

## 4. 모양 규칙 (입체감의 정체)

- 둥근 모서리: 카드 14px, 표·박스·판 12px, 버튼·입력 칸 10px, **표 안 작은 칸·작은 단추 8px(#1218 · 이미 110곳)**, 칩/배지 999px(알약), 동그라미 50%. 4·6px 는 새로 쓰지 않는다.
- **누름 영역 44px 이상(#1218)**: 폰·PC 공통. 보이는 크기가 작으면 `::before` 로 누름 영역을 넓힌다. 보이는 높이 = 주 단추 44 · 표 안 단추 32~36.
- **판(모달)**: 뒤 바탕 `rgba(16,24,40,.45)` · 모서리 16 · 그림자 떠있는 요소 값 · Esc·바깥 누름으로 닫기 · **닫을 때 history.back 금지**.
- **z-index 단계(새 값만)**: 드롭다운 100 · 고정 머리 200 · 판 1000 · 판 위 판 1100 · 알림 1200 · 달력 팝업 1300 · 9999 금지. 기존 930~980 은 겹침 사고 위험이 있어 그대로.
- **포커스·움직임**: `outline:none` 은 `:focus-visible` 대체 규칙과 함께만 · `transition: all` 금지(속성을 적는다) · 움직임이 있으면 `prefers-reduced-motion` 한 줄.
- 그림자(은은하게): 기본 `0 1px 3px rgba(16,24,40,.06)` · 떠있는 요소 `0 4px 16px -6px rgba(16,24,40,.12)` · 주 버튼 `0 6px 16px -6px rgba(79,70,229,.55)`.
- 헤더류 배경: 옅은 그라데이션 `linear-gradient(#FBFBFD, #F4F5F8)`.
- 호버: 표 행 `#F8F9FC`, 인디고 요소는 `--primary-light`.

## 6. 레이아웃·모바일 원칙

- 표가 조건(필터)·집계와 함께 있으면: 조건·집계는 화면에 남고 표만 래퍼 안에서 스크롤(엑셀 틀고정 느낌).
- 모바일(≤768px): 일정 헤더는 2줄(제목+새로고침 / 토글·오늘·이동), 긴 텍스트는 칸 밖으로 밀지 말고 줄바꿈·축소(`min-width:0` 필수), 터치 버튼 40px+.
- 모달: 완료 체크 등 반복 조작은 **창을 닫지 않고** 상태만 갱신(대표 지시, 정산 날짜 모달 참조).

## 7. 작업 절차 (디자인 건드릴 때)

1. 이 가이드 + `theme.css`(색·모양 오버레이) + `styles.css` 하단 블록들(v5.9.69~79 주석) 확인.
2. 새 스타일은 기존 토큰·컴포넌트 재사용. 화면별 예외는 클래스 스코프로(전역 오염 금지).
   - 화면 전용 별칭(`--d-*`·`--f-*`·`--x-*`)은 **테마 토큰을 가리키기만** 한다(`--f-ink: var(--text-dark)`). 별칭에 새 값을 박지 않는다. 필요한 값은 theme.css 에 먼저 올린다(#1218).
   - **새 코드에서 인라인 `style="color:#…; font-size:…"` 금지** → 클래스(인라인 색은 야간이 속성 글자로 겨우 따라감). 예외: 인쇄물·PDF·캡처 이미지(맑은 고딕 예외와 같은 곳)(#1218).
   - 클래스 이름을 `body`·`html` 상태 표시에 쓸 때는 화면 부품 클래스와 겹치지 않게(#1218 사고 = 메모함이 body 에 붙인 `om-open` 이 줄 단추 규칙과 이름이 같아 화면 글꼴이 바뀜).
3. 큰 변경은 시안(HTML 목업, `디자인시안_v1_2026-07-26.html` 방식)으로 먼저 보여주고 대표 "콜" 후 반영.
4. 배포 전: `node --check` → 버전·캐시(v=NNN) 상향 → CHANGELOG → `npm run deploy`. 실험성 변경은 원복 쉽게 **한 블록**으로.
5. 병행 세션 주의: 커밋 전 `git log`·`git status` 확인, 내 파일만 add.
