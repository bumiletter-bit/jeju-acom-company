## 알리고 템플릿 규격 공통

- 변수 표기: `#{변수명}` — 발송 시 호출자(회사프로그램)가 실제 값으로 치환한 완성 문장을 전송 (승인 템플릿과 불일치 시 발송 실패)
- 본문 최대 **1,300자** (한/영 무구분·띄어쓰기 포함 — 공식 확정)
- 버튼: **채널 추가**(AC) 1개 — 본문이 비광고성이어야 하며 안내 문구는 카카오 고정. D(회원가입)는 혜택 문구와 버튼을 인접 배치하지 말 것("채널 추가의 대가"로 읽히면 반려)
- 심사 시 **전 변수에 예시 텍스트 필수** — 예시에도 광고 단어(특가·최상급 등) 금지 (심사는 변수 예시를 본문으로 봄)

## 환경변수 키 (확정 — 값은 대표가 Render에 직접 투입, 코드·로그 노출 금지)

| 키 | 용도 |
|---|---|
| `ALIGO_API_KEY` / `ALIGO_USER_ID` | 알리고 인증 (알림톡·문자 공용) |
| `ALIGO_SENDER_KEY` | 발신프로필 키 (카카오 채널 연동 시 발급) |
| `ALIGO_SENDER` | 발신 전화번호 |
| `ALIGO_TPL_CODE` / `_RESERVE` / `_WELCOME` | 템플릿 3종 코드 — 검수 승인 후 투입 (`_DELIVERED`는 C 폐기로 미사용) |
| `KAKAO_NOTIFY` | 발송 마스터 스위치 (`on`일 때만 실발송 — 기본 off) |
| `ALIGO_TEST` | `Y`면 문자 API 과금·실발송 없는 연동 테스트 |
