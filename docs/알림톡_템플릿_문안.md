# 알림톡 템플릿 문안 (대표 확정 — 지시 #74)

> ⚠️ **등록 보류 중 (지시 #75)**: 알리고/카카오 검수 신청은 다음 주 대표 GO 사인 전까지 보류.
> 로고 이미지(이미지 알림톡) 포함 등 문안·디자인 다듬은 후 별도 지시로만 진행.
> 이 문서는 규격 정리본 — GO 사인 후 API(`/akv10/template/add/` → `/akv10/template/request/`)로 등록.

## 알리고 템플릿 규격 공통

- 변수 표기: `#{변수명}` — 발송 시 호출자(회사프로그램)가 실제 값으로 치환한 완성 문장을 전송 (승인 템플릿과 불일치 시 발송 실패)
- 사용 변수 3종: `#{고객명}` `#{상품명}` `#{발송안내}`
  - `#{발송안내}` = shipping-schedule.js 자동 계산 (예: "내일 수요일 오전 발송, 목~금 도착 예정") 또는 휴무 기간 안내 문구(지시 #73)
- 버튼: **채널 추가** 버튼 1개 (버튼 타입 AC — 카카오 규격상 채널추가 버튼은 심사 가점)
- 템플릿 내용 최대 1,000자

## 환경변수 키 (확정 — 값은 대표가 Render에 직접 투입, 코드·로그 노출 금지)

| 키 | 용도 |
|---|---|
| `ALIGO_API_KEY` | 알리고 API 키 (마이페이지 발급 — 알림톡·문자 공용) |
| `ALIGO_USER_ID` | 알리고 계정 ID |
| `ALIGO_SENDER_KEY` | 발신프로필 키 (카카오 채널 연동 완료 시 발급 — 알림톡 전용) |
| `ALIGO_SENDER` | 발신 전화번호 (예: 01066874031) |
| `ALIGO_TPL_CODE` | 템플릿 1(일반 주문) 코드 — 검수 승인 후 |
| `ALIGO_TPL_CODE_RESERVE` | 템플릿 2(예약 상품) 코드 — 검수 승인 후 |
| `KAKAO_NOTIFY` | 발송 마스터 스위치 — `on`일 때만 실발송 (기본 off = dry-run) |

## 발송 안내문(LMS) 채널 — 지시 #74 STEP1

- 품목별 장문 안내(먹는법·보관법·후숙 팁)는 알림톡이 아닌 **LMS(알리고 문자)** — 자유 문안·심사 불필요
- 문안은 [문의 관리] > 판매현황·가격 탭의 "📦 발송 안내문" 열에서 품목별 관리 (bot_products.shipping_guide)
- `{{내일요일}}`·`{{모레요일}}` 플레이스홀더 = 발송 당일 기준 배달 가능일 1·2번째 요일로 자동 치환
