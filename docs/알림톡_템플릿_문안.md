## 발송 안내 채널 — 대표 확정(#93, #88 LMS 단독 권장 번복)

- **알림톡 E 우선 → 실패 시 SMS 대체** (모든 고객 접점 알림톡 일관성). SMS 대체 문면 = 기존 품목별 장문 안내(먹는법·보관법·후숙) 그대로 — 판매현황 탭 "📦 발송 안내문"에서 품목별 관리, `{{내일요일}}`/`{{모레요일}}` 자동 치환.
- E 템플릿 미승인·코드 미투입 동안은 SMS(기존 LMS)로 직행 — 코드가 자동 판단.
- 실측(2026-07-29): 안내문 19종 길이 414~561자 — SMS(LMS) 한도(2,000byte) 내 전부 수용 가능.
