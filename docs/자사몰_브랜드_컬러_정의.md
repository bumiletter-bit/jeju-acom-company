## 5. 다음에 손댈 때 지킬 것

1. 새 화면을 만들면 `:root`를 **1번 표 그대로** 복사해 시작할 것.
2. 공통 컴포넌트(탭·헤더·버튼)는 값을 **하드코딩하지 말고** 이 표의 토큰을 쓸 것. 단 화면별 `:root` 값이 갈라져 있는 동안에는 탭처럼 "전 화면 동일"이 요구되는 항목만 예외적으로 고정값(`#1B3A6B`·`#FFF8DC`)을 씁니다.
3. 변수명 `--navy`가 딥 그린을 담고 있는 불일치는 **다음 정리 때 이름을 바꾸는 것을 권장**합니다(지금 바꾸면 전 화면 치환이 필요해 이번 범위에서 제외).
