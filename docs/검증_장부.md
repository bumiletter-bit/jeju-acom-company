# 검증 장부 — 이 파일을 고치면 돌릴 검증

> #1189(2026-11-18 · 워커1) · `scripts/verify-*.js` 291개의 머리 주석과 불러 쓰는 파일을 기계적으로 뽑아 지금 쓸 것만 골랐다(#900 이후 우선 · 같은 대상을 더 새 검증이 덮는 옛것은 뺌).
> 🔴 돌리기 전에 **그 스크립트 머리 주석을 먼저 읽는다**(꼬리표가 낡았을 수 있음 · 메모리 feedback-read-verify-header-first).

## 쓰는 법(맨 먼저)
1. **작은 수정**(한 화면·한 칸·함수 하나) = 아래 ①에서 그 파일의 「꼭」만 돌리고, 다른 워커가 읽기 점검. 「넓게」는 돌리지 않는다.
2. **총 점검 · 서버나 여러 화면을 건드린 큰 변경** = 「꼭」 + 「넓게」 + server.js 를 건드렸으면 읽기 전용 기동 1회(`node -r ./scripts/ro-preload-711.js server.js` → /api/version 200).
3. **색을 바꿨으면** `node scripts/ao-dark/gen-dark.js` 다시 돌리고 → 569-dark(메뉴 전체)·568-dark(에이전트 오피스). 색을 안 바꿨으면 돌리지 않는다.
4. **날짜·시각을 다루면** 한 번 더 `TZ=UTC` 로 돌린다(렌더 = UTC · 이 PC = KST 라 우연히 통과함).
5. [실DB 쓰기]·[실AI] 는 **총괄에게 먼저** 묻는다. [Playwright] 는 총괄이 줄 세운 차례에 한 번에 하나만. 포트는 워커마다 따로(3458·3461·3462).
