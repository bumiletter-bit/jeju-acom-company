# 쿠팡 API 키 입력 — 대표님 실행 절차 (SSH)

> 2026-07-26 작성. 쿠팡 키(ACCESS/SECRET)는 **NCP 중계서버 한 곳에만** 넣습니다 (Render에는 넣지 않음 — 네이버와 동일 원칙).
> ⚠️ 키 유효기간 180일 — **2027-01-21 만료**. 일정에 재발급 알림(2027-01-07) 자동 등록됨.

## 준비물
- 쿠팡 개발자센터(Wing)에서 발급받은 **Access Key / Secret Key** (업체코드 A01600270)
- NCP 접속: NCP 콘솔 '관리자 비밀번호 확인'(.pem 첨부) → PowerShell에서 `ssh root@101.79.16.213`
  (⚠️ 인터넷 회선이 바뀌었으면 NCP 콘솔 ACG에서 22번 포트 myIp 갱신 먼저)

## 절차 (복붙 순서대로)

### ① .env 백업
```bash
sudo cp /opt/akkome-relay/.env /opt/akkome-relay/.env.backup
```

### ② 중계서버 최신 코드 + 쿠팡 키 항목 생성 (install.sh 재실행 — 기존 값 보존됨)
```bash
curl -fsSL https://raw.githubusercontent.com/bumiletter-bit/jeju-acom-company/main/relay/install.sh | sudo bash
```

### ③ 키 값 입력 (아래 두 줄에서 `여기에_...` 부분만 실제 키로 바꿔 실행 — 따옴표 유지)
```bash
sudo sed -i "s|^COUPANG_ACCESS_KEY=.*|COUPANG_ACCESS_KEY=여기에_액세스키|" /opt/akkome-relay/.env
sudo sed -i "s|^COUPANG_SECRET_KEY=.*|COUPANG_SECRET_KEY=여기에_시크릿키|" /opt/akkome-relay/.env
```
(VENDOR_ID는 A01600270으로 자동 입력돼 있음)

### ④ 재시작 + 확인
```bash
sudo systemctl restart akkome-relay
sleep 2
curl -sk https://localhost:4000/health
```
확인 포인트: `"version":"2026-07-26.1"` + `"coupang_keys_set":true` 두 개가 보이면 성공.

### ⑤ 회사프로그램에서 최종 확인
[데이터관리] > 🛒 쿠팡 커머스API 연동 > [연결 테스트] → 초록불 확인.

## 문제가 생기면
- `coupang_keys_set:false` → ③에서 키 값이 제대로 안 들어간 것. `sudo grep -c "^COUPANG" /opt/akkome-relay/.env` 로 3줄 존재만 확인(값은 출력 금지) 후 ③ 다시.
- 완전 복구: `sudo cp /opt/akkome-relay/.env.backup /opt/akkome-relay/.env && sudo systemctl restart akkome-relay`
