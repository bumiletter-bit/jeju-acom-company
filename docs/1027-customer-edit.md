## 0. 한 줄
번호 하나 → 그 번호 발송 전 주문 **전부** 주문별 줄(1박스 포함) → 줄마다 [고치기] = #1021 박스별 판(박스 수 = qty · **1박스 허용**) + **주문 단위 발송일 칸** → 저장 = 바꾼 주문마다 줄(아래 2) → 최종발주가 박스별 줄로 카드 미리 채움·양식 반영 · 발송일은 종전 날짜 줄 동작 그대로.

## 1. 꼬리표(워커1)
- 칩 4개 = 주문입력 · 입력삭제 · 사이즈·과수 · **고객정보수정**(날짜 지정·보내는이·메모 수정 칩 3개 뺌). 손님 글 붙여넣기(AI·규칙)가 만드는 날짜·보내는이·배송메모 줄과 저장된 옛 줄은 종전 그대로 읽힘(파서·서버 무변경).
- 「고객정보수정」 = 번호 칸만(꼬리표 칸 없음) → [넣기] 없이 바로 그 번호 주문 찾기(lookup) → 주문별 줄(#938 `ordHtml` 꼴 · 주문 1건이어도 줄로) · 줄 = 품목 n박스 · 주문번호 · 결제일 · **[고치기]** 단추(1박스도).
- [고치기] = #1021 `bxPanel` 그대로(품목 콤보 #1026 · 사이즈 칩/과수 칸 · 받는 분 이름·번호1·번호2·주소 · 배송메세지 · 보내는 분 이름·번호 · 이번에 안 보냄 · 「전부 박스 1과 같게」) + 판 머리에 **발송일 칸 1개**(`om-orddt` 꼴 · 비우면 「다음 발주」 · M/D 입력 · 지난 날짜 막음).
- 저장 단추 = 판의 [저장] 하나(체크·고른 뜻을 저장이 실행 = feedback-save-button-does-pending-action) · 바꾼 주문마다 아래 2의 줄 · **아무것도 안 바꾼 주문 = 저장 0**(안내 「바꾼 것이 없어요」).

## 3. 서버(워커2 · order-memo.js · docs/850-api.md §9)
- `cleanBoxes`: 길이 **1~20**(종전 2~20 → 1 허용) · 그 밖 종전.
- `boxesOf`/`isBoxRow`: `v.length >= 1`.
- `lineBadge` 박스별 줄 글 = **「주문수정 n박스」**(종전 「박스별 n박스」 대체 · 모든 박스별 줄 통일) · 판정 종전(그 주문 qty 합 == n → ok).
- `pickForShip`: 종전(ship_date 없음·= date → box_rows · > date → box_wait · < date → held) · ⓐ 날짜 줄은 종전 lines 길.
- 850-api §9 = 길이 1~20 · 배지 글 한 줄.

## 4. 최종발주(워커3 · final-order.js)
- `OMF.boxRows` 받기 = `boxes.length >= 1`(종전 ≥2).
- `boxPlan` = 종전(주문 1줄 · `boxes.length === qtyNow` · 1박스면 1==1) → `st.omBoxes`.
- 직접 고치기 카드 = 그 주문에 메모함 박스별 값이 있으면 **1박스 주문도 박스 줄 UI 로**(boxQ = 1 · 저장 순서 om.arr 미리 채움 · 보내는 분 2칸) · 없으면 종전(1박스 = 박스 줄 없음).
- 양식 = `boxesOf` → make() 묶음 1개 → 줄 1개에 바뀐 칸만(옵션·꼬리·받는 분·메모·보내는 분 연보라) · 종전 #1021 길.
- 뒤 날짜 주문(ⓐ 로 보류) = 오늘 양식에 안 나감 · ⓑ 는 box_wait 라 안 옴 · 그날 둘 다 옴.
- box_rows 없으면 파일 바이트 종전(verify-1021-fo Ⅰ).
