## 1. 심사 기준 요약

### 1-1. 알림톡이란 (전제)

> 원문: "알림톡은 카카오톡 채널을 추가하지 않은 이용자에게도 발송할 수 있는 정보성 메시지로, 정보통신망법 및 카카오의 내부 기준에 따라 템플릿 심사가 진행되며, **승인된 템플릿만 발송이 가능**합니다." (심사 가이드 도입부)

- 카카오 심사를 통과했더라도 발송이 법령 위반이면 **법적 책임은 전송자(사업자)** 에게 있음 (원문 명시).
- > 원문: "이용자 신고가 다수 접수될 경우 소명 여부와 관계없이 **사업자등록번호 기준으로 서비스가 차단**되어, 알림톡 및 브랜드 메시지 사용이 **영구적으로 중지**될 수 있으니 주의"
- 발송에는 "적법한 목적과 절차에 의해 수집된 전화번호만 사용" (알림톡 소개 페이지 원문).

### 1-2. 정보성 vs 광고성 판정 기준 (원문 인용)

**정보성 메시지 정의** (심사 가이드 §1):
> "정보성 메시지란 정보통신망법 안내서에 **'영리목적의 광고성 정보가 아닌 정보'** 에 해당하는 메시지로, 수신자가 영리목적의 광고성 정보의 수신을 거부하더라도 전송자와 수신자 간 **계약이나 거래 관계로 인하여 전송자가 수신자에게 반드시 전달해야 할 필요가 있는 정보**는 광고성 정보의 예외에 해당합니다."

정보성으로 인정되는 범주 (심사 가이드 §1 원문 요지):
1. **수신자의 요청·신청에 따라 전송하는 정보** (견적서, 상품 카탈로그 등 계약체결을 위한 정보, 경품·사은품 지급 정보) — 단, 다른 재화·서비스 홍보가 섞이거나 추가 요청 없이 반복 발송하면 광고성.
2. **계약이행 등에 관한 정보** (설명서, 확인·보증사항, 변경사항, 안전·보안·업데이트 등 계약 관련 고지).
3. **유상거래 기반 '적립식 포인트'의 소멸 고지** (광고성 아님).
4. **이용자의 적극적 행위로 발급된 쿠폰의 발급·소멸 안내** (광고성 아님. 단 "이용촉진 목적으로 과도한 불편 초래 금지").
5. **오로지 공익 목적 무상 제공 서비스·재화 정보** (장학금 지급 안내 등).
6. 안내성 정보에 **광고성 정보 수신동의 요청을 '간단하게' 추가**한 경우는 안내성 유지 (단, 오로지 수신동의 수집 목적의 발송은 법 위반. 수신동의 요청이 본문 가시성을 훼손하면 안 됨).

**광고성 메시지 판단 기준** (발송 유의사항 페이지 §4.1 원문):
> "➊ 특가/할인 상품안내 ➋ 상품 및 서비스 홍보를 위한 프로모션 또는 이벤트 ➌ **정보를 '주'로 나타내더라도 (➊,➋)의 내용이 혼재된 경우**"

→ 핵심: **본문 대부분이 정보성이어도 광고 문구가 한 줄이라도 섞이면 광고성으로 판정**됨(혼재 기준).

### 1-3. 알림톡으로 보낼 수 있는 메시지 유형 (심사 기준 A·B·C)

심사 가이드 §2 구조:
- **A = 정보성 메시지** (위 1-2 정의 충족)
- **B = 알림톡 서비스 기준 및 발송 가능 예시 메시지** ('알림톡 발송 예시' 페이지의 발송 가능 예시 정책)
- **C = 발송 불가 예시 메시지**
- **승인 = A, B 모두 충족** / **반려 = A·B 중 하나라도 미충족 또는 C 해당**

> 원문 9): "알림톡으로 발송 가능한지의 여부 판단은 알림톡 발송 예시 > 발송 가능 예시 정책을 따릅니다. **발송 가능하다고 명기한 경우 외에는 모두 발송이 불가**하며, 발송 가능 예시에 없으나 1) 및 2)의 기준에 부합하는 경우 카카오 내부 검토를 거쳐 발송 가능 예시에 추가함으로써 발송할 수 있습니다."

발송 가능 예시 카테고리(발송 예시 페이지 목차): ①회원가입 ②주문(구매) ③예약/신청 ④구매완료/만족도 조사 ⑤포인트/마일리지/쿠폰 ⑥안전/보안 ⑦금융 ⑧정당 ⑨법적 고지 ⑩청소년 유해 매체물(인증 조건부) ⑪기타 안내/알림.

추가 조건 (심사 가이드 §2 원문):
- 2) "템플릿은 **형식화가 가능한 정보성 메시지**에 한해 발송 가능" — "수신자 정보만 달라지고, 일정한 조건에서 항상 동일한 내용으로 발송되는 메시지". **간헐적 공지사항은 알림톡 발송 불가**.
- 3) 예외: 수신 방식의 일관성이 수신자에게 유리하면(대부분 알림톡+주1회 이상 수신 상황에서 일부만 문자인 경우) 기준 밖이어도 허용 고려 가능.
- 5) 심사는 "템플릿 상에 기재된 고정값 및 변수의 예시만" 대상 — 링크 내부, 포인트 적립 절차 등은 심사 대상 아님(승인이 적법성 보증 아님).
- 8) 서비스 기준·발송 예시에 없어도 법상 '비광고성'이면 **심사 담당자와 사전 협의 후 발송 가능**.
- 심사 처리 기한: > "심사 요청하신 템플릿은 **영업일 기준 2일 이내 순차 처리**되며, 반려된 템플릿은 수정하시어 재심사 요청해야 합니다."

### 1-4. 수신자 조건

- 계약·거래 관계가 있는 수신자에게 "반드시 전달해야 할 필요가 있는 정보"만 (1-2 정의).
- **채널 친구(채널 추가) 여부 무관** 발송 가능 — 알림톡의 정의 자체.
- 적법하게 수집된 전화번호만 사용 (소개 페이지 원문).
- 포인트/쿠폰 안내는 **"회원에게 제공된 경우에만 가능 (비회원 발송 불가)"** (발송 예시 §5 원문).
- 청소년 부적절 업종·콘텐츠는 연령 인증 메시지 또는 성인 인증 채널 필요 (심사 가이드 §2-6, 발송 유의사항 §2-1). 알림톡에서는 "청소년 유해 콘텐츠의 **쿠폰 지급/소멸, 라이브 방송, 신제품 알람** 안내 메시지의 발송이 제한" (심사 가이드 6) 각주).

## 3. 템플릿 유형별 규격

가이드의 실제 분류(알림톡 유형 페이지 content-guide 기준):
- **1. 메시지 유형**: 기본형 / 부가정보형 / 채널추가형 / 복합형
- **2. 강조 유형**: 이미지형 / 강조표기형 / 아이템리스트형
- **3. 미리보기 메시지** (부가 설정)

> 글자수 단위 원문 공통 표현: "텍스트 문구 **한/영 구분없이 띄어쓰기 포함**" N자 제한.

### 3-1. 기본형

| 구성요소 | 규격 (제작 가이드 도판 원문) |
|---|---|
| 내용(본문) | 한/영 구분 없이 띄어쓰기 포함 **1,300자** 제한 |
| 버튼 | ① 버튼명: 띄어쓰기 포함 **14자** 제한 ② **변수 사용 불가** ③ **최대 5개(세로 배열)** |

- 용도 원문: "고객에게 반드시 전달되어야 하는 정보를 발송할 수 있습니다."

### 3-2. 부가정보형

| 구성요소 | 규격 |
|---|---|
| 내용(본문) | 1,300자 제한 — **부가정보 500자 포함** (본문+부가정보 합산 1,300자) |
| 부가 정보 | ① 띄어쓰기 포함 **500자** 제한 ② **변수 사용 불가** ③ **URL 포함 가능** — 본문과 버튼 사이 Description 영역에 노출, 본문 대비 사이즈 -1pt·컬러차 자동 적용 |
| 버튼 | 기본형과 동일 (14자·변수 불가·최대 5개 세로) |

- 용도·조건 원문 (content-guide §1-1-2): 부가정보 영역은 "광고성 요소와 동시 사용이 가능", "매월 정기적으로 발송되는 메시지 하단에 광고 메시지가 링크로 포함 된 경우 사용" (카드 청구서·유료 멤버십 월 갱신 등).
  - 경고 힌트 원문: "이벤트에 대한 간단한 안내 외의 '아래 버튼을 누르시면 이벤트(또는 광고) 페이지로 이동합니다.'를 필수로 안내", "**광고 메시지는 '변수 사용'과 'url 포함'이 불가능**", "페이지 이동은 WL(웹링크) 버튼 타입".

### 3-3. 채널추가형

### 3-5. 이미지형 (강조 유형)

| 구성요소 | 규격 (제작 가이드 도판 원문) |

| 이미지 | *템플릿 당 **하나의 고정 이미지**만 사용 가능 / *이미지 **클릭 시 링크 연결 불가** ① 가로:세로 **비율제한 2:1** (**500×250px 이하일 경우 업로드 불가**) ② 권장 사이즈 **800×400px** ③ 파일형식·크기: **jpg, png / 최대 500KB** |
| 본문·버튼 | (도판에 별도 표기 없음 — [추정] 기본형 규격 준용. 강조유형 공통 도판: 내용 1,300자·부가정보+채널추가 500자 포함, 버튼 14자·변수불가·최대 5개 세로) |

- 강조 유형 공통 제약 (content-guide §2-1 success 힌트 원문):
  - "이미지 알림톡은 정보성 메시지로 수신자에게 반드시 전달되어야 하는 정보만 발송이 가능... **광고성 메시지 및 이미지에도 광고성 내용이 포함된 경우 발송이 불가**"
  - "포함될 수 있는 이미지는 **발송 주체 또는 발송 주체의 톡 채널 프로필을 대표하는 이미지, 메시지의 목적을 표현하는 이미지로 제한**"
  - "**강조표기형과 동시에 사용할 수 없으며**, 카카오톡 **8.7.5 버전(안드로이드·iOS 공통) 이상**에서만 노출"
  - "이미지 제작 가이드를 준수하여야 합니다" (→ §5 스펙 카드)

### 3-6. 강조표기형 (강조 유형)

## 4. 배송/구매 관련 공식 템플릿 예시 (우리 문안 대조용)

### 4-1. 발송 예시 페이지 §2 주문(구매) — 발송 가능/불가 원문

**1) 주문 완료 안내 — ✅ 발송 가능 예시 원문**
```
[주문완료 안내]
안녕하세요 #{NAME} 님.
#{SHOPNAME} 주문이 완료되었습니다.
- 주문내역: #{주문내역}
- 주문내역 확인: [주문조회 링크]
```
**❌ 발송 불가 예시** (동일 주문완료 문안에 아래가 붙은 경우):
```
📢 빠른 상담 및 혜택 알림을 원하신다면 00채널을 추가해 주세요.
채널 추가 시 제공 혜택!
1) 1,000원 쿠폰  2) 특별 할인쿠폰
```

**2) 구매 확정 요청 — ✅ 발송 가능 예시 원문**
```
#{NAME}님,
주문하신 물품 배송 완료되었습니다.

안전하게 물품을 받아보셨다면
구매 확정을 부탁드릴게요.
감사합니다.
```
**❌ 발송 불가**: 위 문안 + "받으신 상품을 리뷰를 작성해주시면 홈페이지에서 이용할 수 있는 10% 할인 쿠폰을 증정" → 불가.

**3) 배송 현황 안내 — ✅ 발송 가능 예시 원문**
```
안녕하세요. #{NAME}고객님
물품이 택배 #{도착영업소} 배달차량에 상차되어 금일 #{배송시간} 에 배송 될 예정입니다.
```
- 단서 원문: "❌ 발송 가능 예시 외 발송 불가"
- 정보성 기준 원문: "✅주문 확인/ 구매 완료에 대한 정보 전달"

### 4-2. 발송 예시 페이지 §4 구매완료/만족도 조사 — 발송 가능 원문 (요지)

- 구매 상품 관련 안내 ✅: "구매하신 제품의 사용법을 확인해 보세요. 사용법 보기 ☞#{URL}" (신상품 안내 혼재 시 ❌)
- 만족도조사 ✅: 인수 완료 후 "배송 만족도 조사를 위하여 아래 바로가기로 접속해 주십시요. #{url 주소}" (광고 랜딩·자사 쿠폰 대가 ❌)
- 후속 관리 ✅: "1개월(#{구매일자})전 배송 받은 상품의 사용 중 이상이있으면 언제든 연락주십시요." (멤버십 혜택 홍보 혼재 ❌)
