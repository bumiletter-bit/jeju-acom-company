# 카카오 채널 「상담톡」 조사 (#634)

- 조사일: 2026-10-11 · 조사 = 워커3 · 방법 = 공식 문서·공식 안내 페이지 읽기만(계약·신청·발송·코드 0)
- 발단: 대표 10/11 「알리고를 쓰고 있으니 알리고로 되는지 확인」
- 목적: 카카오 채널 1:1 채팅을 문자(#610) 카드와 같은 구도(손님 글 → 서버 → 봇 초안/자동 답 · 직원이 카드에서 나중에 답 보내기 · 사진 수신)로 만들 수 있는지
- 원칙: 추측 금지. 문서에서 못 찾은 것은 「못 찾음」 · 추정은 「추정」으로 표시

## 1. 한 줄 판정

**문자 카드 구도로 되나: 조건부로 된다.**

손님 글을 webhook 으로 받고 세션 안에서 직원이 나중에 보내는 것은 상담톡 API 로 된다(인포뱅크·해피톡 문서에 수신 webhook 과 발송 API 가 있음). 조건은 셋이다.

1. 알리고가 아니라 카카오 공식 상담톡 딜러사와 새 계약이 필요하다.
2. 상담톡을 켜면 카카오 채널 관리자센터(웹·앱)의 채팅 메뉴가 비활성된다. 지금 직원이 관리자센터에서 답하던 길이 없어지고 기존 채팅 이력·메모를 조회할 수 없다.
3. 손님이 먼저 말을 걸어야만 세션이 열린다. 우리가 먼저 보낼 수 없다.

**알리고로 되나: 안 된다.** 알리고는 상담톡을 제공하지 않는다(근거는 3절 ①).

## 3. 조사 항목별 답

### ① 알리고가 상담톡을 제공하는가

제공하지 않는다. 근거는 세 가지다.

- 알리고 API 안내 페이지의 발송 종류 = SMS · LMS · MMS · 카카오 알림톡 · 친구톡(텍스트형·이미지형)뿐이다.
- 알리고 카카오 상품 소개 페이지 = 알림톡 · 브랜드메시지(각 API 포함)뿐이고 상담톡 언급이 없다.
- 카카오 공식 상담톡 딜러사 목록에 알리고가 없다.

알리고가 「상담톡을 하지 않는다」고 명시한 문장은 못 찾았다. 확정하려면 알리고 고객센터(02-511-4560) 문의가 필요하다(대표 확인 필요). 알리고 관리자 로그인 화면은 들어가지 않았다.

### ② API 연동형 파트너

우리 구도(우리 서버가 받고 보냄)에 맞는 곳은 **인포뱅크**와 **해피톡** 두 곳이다. 채널톡은 자체 상담 화면형이다.

카카오 공식 안내의 딜러사 목록(페이지 읽기 기준 8곳): 스펙트라 · 블룸에이아이 · 트랜스코스모스코리아 · 인포뱅크 · 한국클라우드 · 채널코퍼레이션 · 디케이테크인 · 더화이트커뮤니케이션. 다른 검색 요약에는 4곳으로 나와 수가 어긋난다. 계약 전에 페이지를 직접 한 번 확인할 것.

### ③ 상담톡으로 되는 것 · 안 되는 것

카카오 공식 안내(kakaobusiness.gitbook.io/main/ad/cstalk)에서 확인된 것:

- 상담톡은 비즈메시지 API 상품이고 공식 딜러사를 통해 도입한다. 「고객센터용 채팅 상담 시스템 자체 구축은 서비스 범위 밖」이다. 화면은 우리가 만들거나 솔루션을 사야 한다.
- 이용 조건: 비즈니스 채널 전환 + 홈공개 ON.
- 손님이 먼저 말을 걸어야 세션이 시작된다. 세션이 끝나면 손님이 다시 말을 걸 때까지 보낼 수 없다.
- 손님 이름·프로필 사진은 주지 않고 식별값(user_key)만 준다. 번호로 주문을 찾을 수 없으므로 문자(#610)의 「번호를 알아보는 봇」은 그대로 못 쓴다.
- 발신 유형: 텍스트 1,000자 · 이미지 5MB(jpg·png·gif) · 파일·동영상 300MB · 오디오 10MB · Rich(텍스트형·이미지형·와이드·리스트·캐러셀).
- 챗봇: 상담원에게 바로 연결하지 않고 자동 응답 챗봇으로 FAQ·분류를 먼저 둘 수 있다. 단 챗봇 수발신 내용은 상담톡에서 바로 조회되지 않는다.
- 상담톡을 정식으로 쓰면 채널 관리자 웹·앱의 채팅 메뉴가 비활성되고 기존 채팅 이력·메모를 조회할 수 없다(프로필 설정·단체 메시지는 그대로).

| 기능 | 판정 | 근거 |
|---|---|---|
| 손님 글 수신(webhook) | 된다 | 인포뱅크·해피톡 문서 |
| 나중에 보내기(세션 안) | 된다 | 인포뱅크 「세션이 생성된 상태에서만 발송」 · 세션 30일 |
| 먼저 보내기 | 안 된다 | 카카오 공식 안내 |
| 이미지 보내기 | 된다 | 카카오 공식 안내 · 딜러사 파일 업로드 API |
| 사진 수신 | 미확인 | 인포뱅크 문서에 묶음 이미지 문구는 있으나 형식 못 찾음 |
| 봇 ↔ 상담원 전환 | 된다 | 카카오 공식 안내 · 인포뱅크 `bot` 파라미터 · 종료 후 봇 이벤트 |
| 야간 자동응답 | 미확인 | 상담시간 관리·시스템 메시지 API 이름만 확인 · 동작 설명 못 찾음 |
| 알림톡 [문의하기] 버튼으로 온 채팅 | 미확인 | 버튼 종류(BC·BT) 명세를 공식 문서에서 못 찾음 |
| 손님 번호·이름 받기 | 안 된다 | 카카오 공식 안내(user_key 만) |

### ④ 카카오 채널 자체 요금

공식 요금 문서를 못 찾았다. 「채널 1:1 채팅 무료」는 딜러사 블로그 설명뿐이고, 챗봇 무료 전환은 2022년 카카오 보도자료다. 상담톡 요금은 카카오 문서에 없고 딜러사 문의로 안내된다.

### ⑤ 톡톡봇 `/kakao-skill`(오픈빌더 스킬)과 같이 둘 수 있는가

근거가 있다. 카카오 공식 안내(챗봇 먼저 → 상담원)와 인포뱅크 문서(`bot` 파라미터 · 상담 종료 후 봇 이벤트 말블럭 실행)가 봇과 상담톡 동시 사용을 전제로 한다.

다만 「봇이 답하는 구간에 온 손님 글도 webhook 으로 오는지」는 근거를 못 찾았다. 문서상 상담 모드와 봇 모드가 갈리고 챗봇 대화는 상담톡에서 보이지 않는다고 되어 있어, 봇 구간 글은 스킬로만 올 가능성이 크다(추정 · 미확인).

## 4. 구현 때 걸릴 것(문서에 적힌 사실)

- 인포뱅크·해피톡 모두 2026-01 부터 카카오 정책 변경으로 수신 `content` 필드가 제거됐다(`contents` 로). 해피톡은 「챗봇 대화 내역 조회 API 2026-06-30 종료」 공지가 있다. 규격이 바뀌는 중이므로 계약 전에 최신 문서를 다시 확인할 것.
- 인포뱅크 webhook 은 5초 안에 200 응답이 필수다. 받자마자 큐에 넣고 응답하는 꼴(문자 #610 과 같음)이어야 한다.
- 인포뱅크 문서 안에 주소 불일치가 있다(종료 후 봇 이벤트 예시 cURL 이 `/v1/cstalk/end` · 채팅 활성화 예시 경로가 본문과 다름). 실제 호출 전에 확인할 것.
