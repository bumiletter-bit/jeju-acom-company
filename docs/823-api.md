# #823 계산서 발행현황 — 묶음 머리 자료 바꾸기(서버 계약 · 워커2 → 워커1)

대표 결정(10/22): ①시온·효돈 머리 = 「누적 정산 / 누적 계산서 / 누적 미발행 잔액」(월 차이 뺌 · 이월 포함) ②CJ 머리 = 「우리 박스 / 계산서 박스 / 차이 n박스」 + 달 단위 [대조 확인] ③「미분류 n통」 알림 = 안 만듦.
보정(총괄 10/22 · 워커3 조사): settlements 는 2026-03-03 부터라 기준일 = 2026-03-29(법인 첫 계산서) + 기준일 시점 이월(carry) · CJ 3,100 = 합계(부가세 포함) 기준 · 허용 박스 차이 = 설정.

종전 칸(`settle_total` · `settle_basis` · `diff` · `issued_total` · `confirmed_total` · `count` · `check_count`)은 **그대로 남는다**(호환). 화면은 새 `stats` 를 쓴다. 줄 단위 [확인]/[보류]·찾기·기간·PDF 무변경. **칸 이름 고정.**

## 0. 설정(`agent_office_config 'tax_invoice'` · 총괄이 실DB 에 넣음 · 코드엔 기본값만)
```json
{ "balance_start": { "date": "2026-03-29", "sion": { "carry": 0 }, "hyodon": { "carry": 0 } },
  "cj_box_tolerance": 30 }
```
- 없거나 틀리면: `date` = `2026-03-29` · `carry` = 0(음수 허용 · 원 단위 정수) · `cj_box_tolerance` = 30(JSON 숫자이고 0 이상일 때만 · null·true·"50" 같은 글자 = 30).

## 1. GET /api/tax-invoices?from&to (또는 ?month) — 묶음마다 `stats` 추가

권한 = 종전과 같음(adminOnly = 대표·경리 · 직원 403).

```json
{
  "from": "2026-09-01", "to": "2026-10-31", "month": null, "months": ["2026-09", "2026-10"],
  "rows": [ "…종전 그대로…" ],
  "groups": [
    { "supplier": "sion", "label": "시온(조천감귤농협)", "…종전 칸…": "…",
      "stats": { "mode": "balance", "start_date": "2026-03-29", "carry": 0,
                 "cum_settle": 1260099, "cum_invoice": 1510099, "balance": -250000 } },
    { "supplier": "hyodon", "…": "…", "stats": { "mode": "balance", "…": "sion 과 같은 꼴" } },
    { "supplier": "cj", "label": "CJ대한통운(택배비)", "…": "…",
      "stats": { "mode": "boxes", "unit": 3100, "vat_included": true, "tolerance": 30,
                 "our_boxes": 117.3, "invoice_boxes": 709.7, "diff_boxes": 592.4, "ok": false,
                 "month_rows": [
                   { "month": "2026-09", "our_boxes": 99, "invoice_boxes": 0, "diff_boxes": -99, "ok": false, "check": null },
                   { "month": "2026-10", "our_boxes": 18.3, "invoice_boxes": 709.7, "diff_boxes": 691.4, "ok": false,
                     "check": { "by": "대표", "at": "2026-10-22T05:10:00.000Z" } } ] } }
  ],
  "totals": { "…": "종전 그대로" }
}
```

### 시온·효돈 `stats` (mode `balance`)
- `start_date` · `carry` = 설정 `balance_start`.
- `cum_settle` = `start_date` ~ **`to`** 우리 정산 합계(대성(시온)/효돈농협 · 정산관리와 같은 단가 재계산 = settleTotals 와 같은 함수 · settlements 날짜로 양끝을 자름 = `cum_invoice` 와 같은 끝).
- `cum_invoice` = `start_date` ~ `to` 계산서 합계(`total_amount` · 보류 뺌 · 날짜 = 작성일(못 읽은 줄은 받은 날 KST · 그런 줄은 금액이 비어 0)).
- `balance` = `carry + cum_settle − cum_invoice` = **누적 미발행 잔액(이월 포함)** · + = 정산은 했는데 계산서가 덜 옴 · − = 계산서가 더 옴.
- `to` 가 `start_date` 보다 앞이면 `cum_settle` = `cum_invoice` = 0 · `balance` = `carry`.

### CJ `stats` (mode `boxes`)
- 달(`months`)마다 `month_rows` 1줄(오름차순):
  - `our_boxes` = 그 달 정산 박스 수(qty 합 · 종전 CJ 셈) + 그 달 `cj_carryover` 금액 ÷ 3,100 · 소수 1자리.
  - `invoice_boxes` = 작성일이 그 달인 CJ 계산서 **전부**(기간이 달 중간이어도 달 전체 · our_boxes 도 달 전체) `total_amount` 합(보류 뺌) ÷ 3,100 · 소수 1자리.
  - `diff_boxes` = `invoice_boxes − our_boxes`(소수 1자리) · `ok` = `|diff_boxes| ≤ tolerance`.
  - `check` = 그 달 [대조 확인] `{ by, at }`(by = 누른 사람 이름) 또는 `null`.
- 위 칸 `our_boxes`·`invoice_boxes` = `month_rows` 의 합(소수 1자리) · `diff_boxes`·`ok` = 그 합으로 같은 규칙. `from~to` 에 걸린 달마다 한 줄.
- `vat_included` = true(3,100 은 부가세 포함 합계 기준 · 표시용).

## 2. POST /api/tax-invoices/check — 달 단위 [대조 확인] / 되돌리기

권한 = adminOnly(줄 [확인] 과 같은 검사 · 직원 403).

요청:
```json
{ "supplier": "cj", "month": "2026-09" }
{ "supplier": "cj", "month": "2026-09", "undo": true }
```
- `supplier` = `sion` · `hyodon` · `cj` 중 하나(화면은 cj 만 씀) · 그 밖 400 · `month` = `YYYY-MM`(틀리면 400).

응답 200:
```json
{ "ok": true, "changed": true,  "check": { "supplier": "cj", "month": "2026-09", "by": "대표", "at": "2026-10-22T05:10:00.000Z" } }
{ "ok": true, "changed": false, "check": { "…": "이미 있던 것 그대로" } }
{ "ok": true, "changed": true,  "check": null }
```
- 두 번 눌러도 1줄(두 번째 = `changed:false` · 처음 누른 사람·시각 유지 · 감사 기록 0).
- 되돌리기(`undo:true`) = 줄 지움 · 없던 것이면 `changed:false`, `check:null`.
- 감사 기록 = 바뀐 때만 1줄 · source `tax_invoice` · action `invoice_check` / `invoice_check_undo` · changes `{supplier, month}`.
- 화면은 성공 뒤 GET 을 다시 불러 `month_rows[].check` 로 그리면 됨.

오류: 400 `{ "error": "supplier 는 sion · hyodon · cj" }` / `{ "error": "month 는 YYYY-MM" }` · 403(adminOnly 그대로) · 500 `{ "error": "대조 확인을 저장하지 못했어요 — 잠시 뒤 다시" }`.
