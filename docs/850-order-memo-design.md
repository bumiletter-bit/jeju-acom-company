## 2. 흐름

```
직원(아무 때나)                         다음 날 아침 최종발주(대표)
──────────────                          ─────────────────────
① 메모함에 붙여 넣기                    ③ [주문 불러오기] 뒤 메모 칸이 열리면
   손님 글 그대로 + 한마디                 「메모함 7줄 넣음 · 현금 3줄」 띠 + 메모 칸·현금에 이미 들어가 있음
   (「현금파일에 추가」「S사이즈로」)        (넣기 전 대표가 손으로 쓴 글은 지우지 않고 뒤에 붙임)
② 정리 결과 바로/1~2분 뒤               ④ 발주 끝(파일 만든 뒤) → [메모함 비우기]
   ✅ 확실 = 「내일 발주에 들어감」          오늘 쓴 줄만 비움 · 미래 날짜·🟠 남김 · 30일 되살리기
   🟠 애매 = 확인 카드(고르기·고쳐 쓰기)
```

### ① 넣기
- 입력 = 큰 글 칸 하나 + **빠른 꼬리표 단추**(현금 손님 · 입력삭제 · 사이즈 · 날짜 지정 · 보내는이) — 누르면 글 칸 맨 앞에 한마디가 붙는다(직원이 안 눌러도 AI 가 글에서 읽음).
- 사진 1장도 됨(최종발주 [사진으로 넣기]와 같은 창구 길).
- ⑤ 손님 연락 문자 대화(`public/ao-desk.js` 문자 창) — 대화 아래 **[발주 메모로 보내기]** 단추(+ 손님 말풍선 꾹 누르기 = 그 글만) → 메모함이 열리며 그 글로 **바로 정리** → **정리 결과 미리보기 카드**(칸마다 고칠 수 있음 · 빈칸 빨강) → **[저장]** 을 눌러야 저장(그 전엔 DB 에 안 남음 · [취소] = 아무것도 안 남김). 번호는 그 대화 번호로 미리 채움.
- 저장한 뒤에도 메모함 목록에서 다시 열어 **보기·고치기·지우기**(지우기 = 비운 것 30일).
- 직원이 직접 붙여 넣을 때도 같은 카드 → [저장](붙여 넣기 = [정리하기] → 카드 → [저장]).

### ② 정리(같은 규칙)
1. **규칙 먼저(AI 없이 즉시)**: `final-order-core.js` `sizeLines` · v2 `parseLines` 와 **같은 함수를 그대로 불러** 「번호 + 사이즈」 「날짜 ⇥ 번호 ⇥ 입력o삭제x」 꼴은 바로 ✅.
2. **나머지는 창구 AI**: 새 지시 종류 `kind:'order_memo'`(memo-read 와 같은 숨은 지시 · 결과 읽고 원문 지움). 창구 규칙 문서 = 새 `★에이전트오피스/발주메모_정리.md` — 최종발주_메모읽기.md 의 날짜 표(도착 → 이틀 전 발송 · 토요일·휴무일 · 범위·요일)와 「절대 지킬 것」(지어내지 않음 · 글자 그대로 · 애매하면 sure:false)을 그대로 가져오고, 할 일만 다르다:
   - 메모 칸 줄 만들기: `{ date:'10/27', key:'01012345678' 또는 주문번호, note:'입력o삭제x' | 'S사이즈로' | '보내는이 홍길동', platform:'네이버'|'쿠팡'|'자사몰'|'' }`
   - 현금 행 만들기: `{ bang:true, recv, phone1, phone2, addr, option, qty, memo, buyer_phone, sender, sender_addr }` → 13칸(보내는사람 칸 = 「! 제주아꼼이네」 꼴 · 출고지·박스타입은 비움 — 최종발주가 거래처별로 채움)
   - 품목(옵션정보) = **단가표 이름 그대로**만(최종발주 대화의 `catalog` 목록을 같이 넘김 · 목록에 없으면 🟠)
   - 주소 = 기존 `/api/agent-office/juso`(도로명 검색)로 한 번 대조 → 안 맞으면 🟠 「주소 확인」(창구 주소 정리 규칙 · 메모리 jeju-desk-address-check)
3. **빈칸**: 13칸 중 받는 분·연락처·배송지·옵션정보·수량 가운데 메모에 없는 칸은 비워 두고 빨강 + 이유 한 줄(「주소가 없어요」 「품목을 못 정했어요(목록: 타이벡 5kg 로얄 / 소과 …)」). 카드 맨 아래 「손님께 물어볼 문자 초안」(예: 「안녕하세요 제주아꼼이네입니다. 받으실 주소를 알려 주시면 내일 보내 드릴게요.」 · 문자 대화에서 왔으면 [초안을 답 칸에 넣기] — 보내기는 직원이 누름).
4. **확인 카드(🟠)** 이유는 최종발주 카드와 같은 말: 날짜 애매 · 번호 없음/8자리 미만 · 품목 목록에 없음 · 주소 못 찾음 · 수량 없음 · 같은 번호 두 번 · 지난 날짜. 카드에서 고르면 ✅.

### ③ 최종발주에 자동으로
- 최종발주가 메모 칸을 여는 순간(`final-order.js` 306행 `fo-memo-sec` 보일 때) `GET /api/order-memo/for-ship?date=<기준 발송일>` 1번 → 오늘 쓸 줄만 받음:
  - 메모 칸 줄: 날짜 없는 것 + 날짜 ≤ 기준 발송일 + 날짜가 미래인 「○일 발송」 줄(미래 줄도 넣어야 v2 가 「오늘 안 나감」으로 뺀다 — 지금 대표가 손으로 넣는 것과 같음)
  - 현금 행: 지정 발송일 없는 것 + 날짜 = 기준 발송일
- 메모 칸에 **이미 글이 있으면 덮지 않고 뒤에 붙임** · 띠 「메모함에서 메모 7줄 · 현금 3줄을 넣었어요 [빼기]」 · [빼기] = 넣은 것만 되돌림.
- 현금: 현금파일 칸이 비었으면 메모함 행을 `parseCash` 가 받는 aoa(머리글 13칸 + 행)로 만들어 `st.cash` 에 넣음(**같은 함수 · 같은 대조**) · 직원이 엑셀을 고르면 엑셀 + 메모함 행 합침(같은 구매자 번호·같은 품목 두 번이면 🟠).
- 넣은 순간 각 줄 = `used_on = 기준 발송일`(아직 안 지움).

### ④ 비우기
- 최종발주 결과 화면(파일 만든 뒤) + 메모함 머리에 **[메모함 비우기]**.
- 기본 = `used_on = 오늘 기준 발송일`인 줄만 → 상태 `cleared`(목록에서 사라짐 · 「비운 것 30일」 탭에서 되살리기).
- 남는 것: 미래 날짜 줄 · 🟠 줄 · 오늘 넣은 뒤에 새로 들어온 줄.
- [전부 비우기] = 되묻기 1회(남는 줄 수를 보여 줌).
- 30일 지난 `cleared` 줄 = 하루 1번 **영구 삭제**(db_retention 틀 · 개인정보라 예외적으로 물리 삭제 — 설정 `order_memo.keep_days` 30).

## 3. 데이터 (새 표 2개 · 기존 표 무접촉)

```sql
order_memo_entries (            -- 붙여 넣은 한 번 = 한 건
  id serial PK, created_at timestamptz default now(), created_by text, created_by_id int,
  raw text,                      -- 원문(직원이 붙인 글 그대로 · 개인정보)
  tags text[],                   -- 꼬리표 단추(cash|indiv|size|date|sender)
  source text,                   -- manual | sms:<thread_id> | photo
  status text                    -- reading(AI 중) | done | error
);
order_memo_rows (               -- 정리된 줄(한 건 → 여러 줄)
  id serial PK, entry_id int REFERENCES order_memo_entries,
  kind text,                     -- line(메모 칸 줄) | cash(현금 행)
  ship_date date,                -- 지정 발송일(없으면 null = 다음 발주)
  line text,                     -- kind=line: 메모 칸에 그대로 들어갈 탭 줄
  cells jsonb,                   -- kind=cash: 13칸 배열
  sure boolean, check_why text,  -- 🟠 이유(최종발주 카드와 같은 말)
  used_on date,                  -- 최종발주에 넣은 기준 발송일
  state text default 'open',     -- open | cleared
  cleared_at timestamptz, cleared_by text,
  updated_at timestamptz default now(), updated_by text
);
```
- 원문(`raw`)도 30일 규칙으로 같이 지움.
- 감사 기록 = `audit_logs source 'order_memo'` · changes 에 **줄 수·상태만**(이름·번호·주소 없음).
