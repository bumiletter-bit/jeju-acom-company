# #814 계산서 발행현황 — 서버 계약(워커2 · 화면 = 워커1)

대표 확정(10/21): 정산관리 안 「계산서 발행현황」 탭 · 확인 전 숫자는 화면에만(어느 합계에도 안 섞음) · 시온 = 월 합계 대조 · PDF 비밀번호 = 설정 `tax_invoice.pdf_password`(코드에 안 박음).

## 1. 표 `tax_invoices` (initDB · 서버 모듈 `tax-invoices.js` 가 CREATE IF NOT EXISTS)

| 칸 | 꼴 | 뜻 |
|---|---|---|
| id | serial | |
| supplier | text | `cj` · `sion` · `hyodon` · `other` (메일 색인 분류 `parsed.supplier`, 없으면 other) |
| supplier_name | text | PDF 의 공급자 상호(못 읽으면 색인의 보낸 이름) |
| supplier_bizno | text | 공급자 사업자번호 `000-00-00000` (못 읽으면 null) |
| approval_no | text | 승인번호 24자리(하이픈 없이 숫자만) · **UNIQUE**(null 은 여러 줄 가능) |
| kind | text | `tax`(세금계산서) · `free`(계산서·면세) · `modify`(수정 발행) |
| orig_approval_no | text | 수정 발행일 때 원 승인번호(읽히면) |
| issue_date | date | 작성일자 — **이 날짜의 달이 그 계산서의 달** |
| supply_amount · vat_amount · total_amount | bigint | 공급가액 · 세액(면세 0) · 합계(원). 못 읽으면 null |
| mail_folder · mail_uid · mail_uidvalidity | text · bigint · bigint | 원 메일(색인 mail_index 와 같은 값) |
| mail_subject · mail_at | text · timestamptz | |
| pdf_name · pdf_data | text · bytea | 풀린 PDF(비밀번호 없는 판) — 보관 정리(report_files 90일)와 무관하게 남김 |
| read_status | text | `read`(숫자 다 읽힘) · `check`(사람 확인 = 그림 PDF·링크형·첨부 없음·일부만 읽힘) · `error`(PDF 못 풂) |
| read_note | text | check·error 사유 한 줄(손님 개인정보 없음) |
| status | text | `draft`(초안 · 기본) · `confirmed`(확인) · `hold`(보류) |
| memo | text | 사람이 적는 메모(≤500자) |
| confirmed_by · confirmed_at | text · timestamptz | 확인/보류 누른 사람 이름·시각 |
| dedup_key | text | **UNIQUE** · 승인번호 있으면 `a:<승인번호>` · 없으면 `m:<folder>:<uidvalidity>:<uid>` (같은 메일 다시 돌려도 새 줄 0) |
| created_at · updated_at | timestamptz | |

- 줄은 지우지 않는다(잘못 들어온 건 `hold` + 메모). 창구 도구가 같은 dedup_key 를 다시 넣으면 **숫자·PDF 만 갱신, status·memo·확인 정보는 그대로**(사람이 누른 것 보존).

## 2. API (전부 `authMiddleware, adminOnly` = 대표·경리)

### GET `/api/tax-invoices?month=YYYY-MM[&supplier=cj|sion|hyodon|other][&date=YYYY-MM-DD]`
```json
{
  "month": "2026-10",
  "rows": [ {
    "id": 12, "supplier": "sion", "supplier_label": "시온(조천감귤농협)", "supplier_name": "조천감귤농협 제주조천점",
    "supplier_bizno": "616-82-00000", "approval_no": "202610054100000012345678", "kind": "free", "orig_approval_no": null,
    "issue_date": "2026-10-05", "supply_amount": 1250000, "vat_amount": 0, "total_amount": 1250000,
    "mail_subject": "…", "mail_at": "2026-10-05T10:12:00+09:00", "has_pdf": true,
    "read_status": "read", "read_note": null, "status": "draft", "memo": null, "confirmed_by": null, "confirmed_at": null
  } ],
  "days": { "2026-10-05": 2, "2026-10-12": 1 },
  "groups": [ {
    "supplier": "sion", "label": "시온(조천감귤농협)", "count": 3, "check_count": 0,
    "issued_total": 3750000, "confirmed_total": 1250000,
    "settle_total": 3760000, "settle_basis": "정산관리 대성(시온) 10월 합계",
    "diff": -10000
  } ],
  "totals": { "count": 7, "issued_total": 0, "confirmed_total": 0 }
}
```
- `rows` = 그 달(issue_date 기준) · supplier/date 가 오면 그것만 · 정렬 issue_date, id.
- `days` = 그 달 날짜별 건수(달력 점 · supplier 거름 적용 전 전체).
- `groups` = 거래처 4개 고정 순서 cj → sion → hyodon → other(0건이어도 줄 있음).
  - `issued_total` = 그 달 **hold 아닌** 줄의 total_amount 합(null 은 0으로 · `check_count` 에 셈).
  - `confirmed_total` = confirmed 줄만.
  - `settle_total` = 우리 정산 월 합계(읽기만): sion = settlements partner `대성(시온)` 그 달 금액 합(정산관리와 같은 단가 재계산) · hyodon = `효돈농협` · cj = 그 달 박스 수(대성·효돈·기타) × 3,100 + cj_carryover(그 달) · other = null.
  - `diff` = issued_total − settle_total (settle_total null 이면 null). **표시만 · 자동 맞춤 0 · 어느 합계에도 안 섞음.**
- `totals` = 그 달 전체.

### GET `/api/tax-invoices/search?q=…`
- 전체 기간 검색(공급자 상호·사업자번호·승인번호·금액(쉼표 무시 숫자 일치)·메모·메일 제목) · 최근 issue_date 순 200건 · 응답 `{ q, rows:[…위와 같은 줄], more: bool }`.

### POST `/api/tax-invoices/:id/confirm` `{ memo? }` → `{ ok:true, row }`
### POST `/api/tax-invoices/:id/hold` `{ memo }`(보류는 메모 필수 · 1~500자) → `{ ok:true, row }`
### POST `/api/tax-invoices/:id/reset` → `{ ok:true, row }` (확인·보류를 초안으로 되돌림)
- 셋 다 audit_logs(action tax_invoice_confirm|hold|reset · target_type tax_invoice · target_id = id · changes before/after status·memo).

### GET `/api/tax-invoices/:id/pdf` → `application/pdf`(inline · 파일 이름 = pdf_name) · 없으면 404 `{ error:'PDF 없음' }`

오류 꼴: `{ error: '사람 말 한 줄' }` · 400(값) · 404(없음) · 500(고정 문구).

## 3. 상태값 정리
- status: `draft` → `confirmed` | `hold` → (`reset`) → `draft`
- read_status: `read` · `check` · `error` — 화면은 check·error 줄에 「원본 확인」 알약 + PDF/메일 제목
- supplier_label: cj = 「CJ대한통운(택배비)」 · sion = 「시온(조천감귤농협)」 · hyodon = 「효돈농협유통」 · other = 「기타」

## 4. 채우는 길(창구 · 워커2)
`node scripts/desk/invoice-month.js <YYYY-MM> [--dry]` — mail_index(kind tax_invoice · 그 달 + 다음 달 10일까지 받은 것) → 첨부 PDF 받기(메일 러너 attach · 읽기 전용) → 설정 `tax_invoice.pdf_password` 로 풀기(PyMuPDF) → 작성일·승인번호·공급자 사업자번호·공급가액·세액·합계 → tax_invoices upsert(dedup_key) · 첨부 없음·그림 PDF·링크형 = read_status check. 결과 글에는 건수만(읽힘/확인 필요/오류).
