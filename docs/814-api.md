# #814 계산서 발행현황 — 서버 계약(워커2 · 화면 = 워커1)

대표 확정(10/21): 정산관리 안 「계산서 발행현황」 탭 · 확인 전 숫자는 화면에만(어느 합계에도 안 섞음) · 시온 = 월 합계 대조 · PDF 비밀번호 = 설정 `tax_invoice.pdf_password`(코드에 안 박음).

## 1. 표 `tax_invoices` (initDB · 서버 모듈 `tax-invoices.js` 가 CREATE IF NOT EXISTS)

| 칸 | 꼴 | 뜻 |
|---|---|---|

| supplier | text | `cj` · `sion` · `hyodon` · `other` (계산서 안 사업자번호 = 설정 `tax_invoice.suppliers` → 없으면 메일 색인 분류 → 없으면 other · 🔴 #816 부터 창구 도구는 other 를 표에 안 넣음 · 예전 other 줄은 남되 화면·검색에 안 나옴) |

## 2. API (전부 `authMiddleware, adminOnly` = 대표·경리)

### GET `/api/tax-invoices?from=YYYY-MM-DD&to=YYYY-MM-DD[&supplier=sion|hyodon|cj]` (#816 · 대표 10/21) · 종전 꼴 `?month=YYYY-MM` 도 됨
- **기간** = `from`~`to`(둘 다 · **day 기준 포함 범위** · 달을 넘어도 됨 · 최대 366일). `from`/`to` 가 오면 `month` 무시. 둘 다 없으면 `month`(그것도 없으면 이번 달 KST 1일~말일).
- 400 = 한쪽만 · `from > to` · 없는 날(2026-02-30) · 366일 넘음 · `supplier` 가 sion·hyodon·cj 밖(other 포함) · month 꼴 틀림. `date` 칸은 없어짐(날짜 칩 삭제).
- 🔴 **화면·검색은 시온·효돈·택배비(CJ) 셋만**(대표 10/21 「기타 필요 없음」) — `supplier = other` 줄은 표에 남지만 rows·groups·totals·search 어디에도 안 나옴. 창구 도구는 이제 기타·제외 낱말(오션라운지) 메일을 표에 넣지 않음.
```json
{
  "from": "2026-10-01", "to": "2026-10-31", "month": "2026-10", "months": ["2026-10"],
  "rows": [ {
    "id": 12, "supplier": "sion", "supplier_label": "시온(조천감귤농협)", "supplier_name": "제주감귤농협 조천지점",
    "supplier_bizno": "616-82-00000", "approval_no": "202610054100000012345678", "kind": "free", "orig_approval_no": null,
    "issue_date": "2026-10-05", "day": "2026-10-05", "supply_amount": 1250000, "vat_amount": 0, "total_amount": 1250000,
    "mail_subject": "…", "mail_at": "2026-10-05T10:12:00+09:00", "has_pdf": true,
    "read_status": "read", "read_note": null, "status": "draft", "memo": null, "confirmed_by": null, "confirmed_at": null
  } ],
  "groups": [ {
    "supplier": "sion", "label": "시온(조천감귤농협)", "count": 3, "check_count": 0,
    "issued_total": 3750000, "confirmed_total": 1250000,
    "settle_total": 3760000, "settle_basis": "정산관리 대성(시온) 10월 합계",
    "diff": -10000
  } ],
  "totals": { "count": 7, "check_count": 1, "issued_total": 0, "confirmed_total": 0 }
}
```
- `month` = month 꼴로 불렀을 때만 그 달 · from/to 꼴이면 `null`. `months` = 기간이 걸치는 달 목록.
- `rows` = 기간 안 줄(**day 기준** · day = issue_date 있으면 그것, 없으면 받은 날 KST(mail_at) — 작성일 못 읽은 check/error 줄도 받은 날에 보이게) · supplier 가 오면 그것만 · 정렬 day, id · issue_date 는 null 그대로.
- `days` 칸 = **삭제**(#816).
- `groups` = **항상 3개 · 순서 sion → hyodon → cj**(0건이어도 줄 있음 · supplier 거름 적용 전 기간 전체).
  - `issued_total` = 기간 안 **hold 아닌** 줄의 total_amount 합(null 은 0으로 · `check_count` 에 셈).
  - `confirmed_total` = confirmed 줄만.
  - `settle_total` = 우리 정산 합계(읽기만) = **기간이 걸치는 달마다 월 합계를 더함**(한 달 안이면 그 달 합계 · 9/15~10/31 이면 9월 + 10월 통째): sion = settlements partner `대성(시온)` 월 금액 합(정산관리와 같은 단가 재계산) · hyodon = `효돈농협` · cj = 월 박스 수(대성·효돈·기타) × 3,100 + cj_carryover(그 달). `settle_basis` = 달마다 근거 글을 「 + 」로 이음.
  - `diff` = issued_total − settle_total. **표시만 · 자동 맞춤 0 · 어느 합계에도 안 섞음.** 🔵 기간이 달 중간에서 끊기면 정산은 그 달 통째라 차이가 크게 보임(화면에 「정산은 달 단위」 한 줄 권함).
- `totals` = 기간 전체(세 거래처) · `check_count` 추가.

### GET `/api/tax-invoices/search?q=…`
- 전체 기간 검색 · **시온·효돈·택배비(CJ) 줄만**(#816) (공급자 상호·사업자번호·승인번호·금액(쉼표 무시 숫자 일치)·메모·메일 제목) · 최근 issue_date 순 200건 · 응답 `{ q, rows:[…위와 같은 줄], more: bool }`.

### POST `/api/tax-invoices/:id/confirm` `{ memo? }` → `{ ok:true, row }`
### POST `/api/tax-invoices/:id/hold` `{ memo }`(보류는 메모 필수 · 1~500자) → `{ ok:true, row }`
### POST `/api/tax-invoices/:id/reset` → `{ ok:true, row }` (확인·보류를 초안으로 되돌림)
- 셋 다 audit_logs(action tax_invoice_confirm|hold|reset · target_type tax_invoice · target_id = id · changes before/after status·memo).

### GET `/api/tax-invoices/:id/pdf` → `application/pdf`(inline · 파일 이름 = pdf_name) · 없으면 404 `{ error:'PDF 없음' }`

오류 꼴: `{ error: '사람 말 한 줄' }` · 400(값) · 404(없음) · 500(고정 문구).

## 3. 상태값 정리
- status: `draft` → `confirmed` | `hold` → (`reset`) → `draft`
- read_status: `read` · `check` · `error` — 화면은 check·error 줄에 「원본 확인」 알약 + PDF/메일 제목
- supplier_label: cj = 「CJ대한통운(택배비)」 · sion = 「시온(조천감귤농협)」 · hyodon = 「효돈농협유통」 · other = 「기타」(화면엔 안 나옴)

## 4. 채우는 길(창구 · 워커2)
`node scripts/desk/invoice-month.js <YYYY-MM> [--dry]` — mail_index(kind tax_invoice · 그 달 + 다음 달 10일까지 받은 것) → 첨부 PDF 받기(메일 러너 attach · 읽기 전용) → 설정 `tax_invoice.pdf_password` 로 풀기(PyMuPDF) → 작성일·승인번호·공급자 사업자번호·공급가액·세액·합계 → tax_invoices upsert(dedup_key) · 첨부 없음·그림 PDF·링크형 = read_status check. 결과 글에는 건수만(읽힘/확인 필요/오류).
